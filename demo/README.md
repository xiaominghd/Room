# demo · 网页版原型（可双击打开）

`index.html` + `styles.css` + `app.js`，没有构建、没有依赖，双击就能在浏览器里跑。
不是截图板：**页面之间是串起来的**，按 PRD 的流程走。

## 打开

双击 `index.html`。左边是跳转与调试，右边是 402×874 的手机。

## 能走通的流程（对应 PRD §12 验收）

| 流程 | 怎么走 | 点完能看到什么 |
|---|---|---|
| 注册 → 建房 | 启动 1.2 秒后进登录 → 「没有账号，注册」→ 注册 | 落在空房：`不用做什么 / 这儿还只有你` + 「去邀请」 |
| 邀请 → 输码 → 进房 | 左栏「开房码」→ 「进入」 | 房间里两个人都在 |
| 发消息 | 打字回车 | 先「发送中」（小点、无时间）→ 0.7 秒后「已发送」（带时间） |
| 失败 / 重发 | 调试「下一条发失败」→ 发一条 | `没发出去 · 重发` → 点重发 → 变已发送 |
| 引用 | **长按**消息 → 引用并回复 | 输入框上方出现整段引用；发出后气泡里带引用块 |
| 发图片 | 房间输入栏左边那个图片按钮 | 真的发出一条图片消息（占位图 + 地点） |
| 录音 | 点麦克风 | 进入录音态（松手发送 / 上滑取消的提示条），再点一次退出 |
| 导出选择 | 导出 → 点范围胶囊 / 点格式那两行 | 选中态会跟着变，生成时按你选的 |
| 此刻改删 | 一天的卡 → 自己那句此刻后面的「改」「删」 | 改会带出原来那句；删掉后回到「写一句」 || 取消引用 | 引用之后点引用条右边的 `×` | 引用条消失，回到普通输入 |
| 引用失效 | 把自己 2 分钟内的被引用消息**撤回** | 引用块变成 `原消息已撤回` |
| 特别记忆 | 长按 → 特别记忆 | 消息下面出现锈色小点；再长按一次变成「取消特别记忆」，只在你这边少一条 |
| 关门 | 按住输入框上沿那条光**往上拖**（或点一下） | 半关：房间变暗 + 可改的「今晚到这儿」输入框 + `关`/`算了`；空着不让关；**5 秒不动自己弹回** |
| 关门之后 | 点 `关` | 全黑，看不到任何消息，只剩关门那句 + `说一句，门就开` |
| 开门 | 关门态点「说一句，门就开」 | 房间亮起 + AI 问一句 + 卡片输入；**这时消息还是看不到** |
| 递卡片 | 点 `递出去` | 卡片作为一张纸进消息流（对方关着门时标「放在对方门口」），排队的话才出现 |
| 门口卡片 | 调试「对方递一张卡到门口」→ 点 `门口有一张卡片` | 用这张卡直接开门 |
| 对方关门 | 调试「让对方关门 / 开门」 | 顶部出现对方关门条；你照发，只有已发出 |
| 对方排队 | 关门时点「对方发一条」 | 话进队列，递出卡片后一起出现 |
| 第 7 天 | 调试「+7 天」 | 相册里 10 月 17 日出现卡 |
| 第 28 天 | 调试「+28 天」 | 房间里 10 月 17 日变成 `已收进相册` 一行 |
| 一天的卡 | 相册 → 点 10 月 16 日 | 卡 + 照片 + 此刻 + 特别记忆小框 |
| 留这一天 | 一天的卡 → 留这一天 → 留 | 顶部冒出「留过 · 原图和原文都留下了，不能取消」；动作行变 `留过` + `看那天的原文`；房间里那行变 `留过`；相册格子右下多个锈点 |
| 看那天的原文 | 留过的卡 → 看那天的原文 | 只读的原文列表 |
| 隐藏 / 恢复 | 一天的卡 → 隐藏这一天 → 隐藏 | 相册里不出现；「隐藏的一天」里能看到并恢复（列表是实时的） |
| 删小框 | 一天的卡 → 你标的特别记忆后面的「删」 | 只在你这边消失；对方标的没有「删」，只标着「阿澄 标的」 |
| 此刻 | 一天的卡 → 写一句 → 保存 | 卡里出现一行，可再改 |
| 翻月 | 相册标题两边的 ‹ › | 翻到 9 月：`这个月还没有` |
| 我的 → 各页 | 我的 → 个人资料 / 账号与安全 / 通知 / 导出 / 运转说明 / 隐私 / 协议 / 反馈 | 都能进能回 |
| 改名 | 个人资料 → 用户名 → 改名 → 保存 | 「我的」里的名字跟着变 |
| 通知开关 | 通知页三个开关 | 能拨，来回切页还记得 |
| 导出 | 导出 → 生成 | 出现「已生成，对方已收到提示」 |
| 退出登录 | 账号与安全 → 退出登录 → 退出 | 回登录页 |
| 离开房间 | 我的 → 离开房间 | 只有一句「离开房间还没定」（这一版只留钩子） |

## 调试面板（只在这个 demo 里）

- **+7 / +28 天**：拨动 demo 的“现在”，看卡生成、原文到期
- **让对方关门 / 开门**：看对方关门条、排队与回来
- **对方递一张卡到门口**：试「门口卡片就是钥匙」
- **对方发一条**：模拟收到消息（你关着门时进队列）
- **下一条发失败**：让下一条走失败态
- **重置**：刷新页面

## 哪些是假的

- 没有账号、没有服务端；登录注册不校验，刷新即重置
- 消息只在本页内存里，不发给任何人
- 图片是暖色渐变占位（fig 里也是图片框）
- 语音不能播，只显示时长
- 通知、开房码校验、导出文件都没有真实现
