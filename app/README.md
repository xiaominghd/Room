# 房间 · Expo 手机 App Demo

产品形态是 IM，所以这个 demo 是手机 App，不是网页。

## 跑起来

1. 手机装 **Expo Go**（应用商店搜 Expo Go）。
2. 手机和电脑连同一个 Wi-Fi。
3. 在 `app/` 目录执行：

   ```bash
   npm install
   npx expo start
   ```

4. 手机扫终端里的二维码；扫不了就手动输入 `exp://<电脑局域网 IP>:8081`。

连不上时（不同 Wi-Fi、虚拟机、防火墙）：

```bash
npx expo start --tunnel
```

## 已经能试的

- 右上角切 **你 / TA**，看两边。
- **停**：单方按、不需要同意；只有按的人能点亮。
- **想聊**：两个人都按才出问题；各答一句，看复述；+1 天看过期。
- **留照片**：点「留」进相册；+7 天聊天没了，照片还在。
- **说给自己**：输入框切「给自己」，写的话只在本机，点「抽屉」看。
- **时间旅行**：+1 / +3 / +7 天，看消息变成「日期 · 条数」。
- **重置**：回到初始状态。

## 这是 demo，不是产品

- 状态在内存里，重启 App 就回到初始种子；没有后端。
- 照片是色块占位，不是真图；语音没做。
- AI 复述是写死的演示逻辑，没有接模型。
- 不验证：推送、安装包、多设备、真机手感。
