# App 页面与跳转说明

> 用途：给实现方（人或 AI）的页面结构规格。
> **不含任何 UI 设计**：没有颜色、字体、字号、间距、圆角、图标样式、动效时长。
> 只写：有哪些页面、每页有什么元素、有哪些状态、能跳到哪。
> 依据：`docs/PRD-v4.md`。

---

## 0. 全局约定

### 0.1 页面类型

| 类型 | 说明 | 返回行为 |
|---|---|---|
| 一级页 | 栈底：启动、登录、注册、房间 | 返回 = 退出 App（iOS 无返回） |
| 二级页 | 从一级页进入 | 返回 = 上一页 |
| 弹层 | 覆盖在当前页上：确认、菜单、看图、抽屉 | 返回 = 关闭弹层 |
| H5 | 站外网页：邀请落地（未装 App） | 无返回，不注册、不登录 |

### 0.2 导航骨架

- **房间是根**：登录后永远落在房间；相册、我的都从房间进，返回都回房间。
- **没有 Tab 栏**，没有会话列表，没有联系人。
- **未登录拦截**：受保护页面先到登录；登录成功后回原目标（深链的房间 ID 必须保留）。
- **弹层不叠弹层**：同一时间最多一层；确认类弹层关闭后回来源页。

### 0.3 深链与通知

- 深链 `…/r/{roomId}`：已装 → 开房码页；未装 → 邀请 H5；未登录 → 登录/注册后回开房码页，房间 ID 不丢。
- 通知点开：消息还在 → 房间并滚到那条；已压缩 → 房间并滚到那天的短记；已定型 → 相册那天的卡。
- 通知点开时门关着：先显示关门页，不硬滚。

### 0.4 统一状态

| 状态 | 表现 |
|---|---|
| 加载 | 页面内一行「加载中」；不整屏遮挡 |
| 空 | 每页有自己的一句话（见各页） |
| 离线 | 不弹全局横幅；只读内容可看，写操作标失败，可重试 |
| 错误 | 页内错误行 + 重试；不弹窗 |
| 权限被拒 | 页内说明 + 去系统设置；不反复弹 |

## 2. 页面详情

### 2.1 启动与准入

#### `launch` 启动

- **作用**：判断会话、房间状态、深链与通知，决定送往哪。
- **元素**：应用标识；一行「正在检查」；错误行；重试；版本过低提示 + 去更新；有目标时的「取消前往」。
- **状态**：
  - 未登录 → `login`（带来源）
  - 已登录有房 → `room`（门关着 → `room` 的关门态）
  - 深链 → `invite-landing`（未登录先 `login`/`register`，保留 roomId）
  - 通知 → 按目标（消息 / 短记 / 一天的卡）
  - 网络不可用 / 服务端不可达 / 登录态失效 → 可重试
  - 版本过低 → 只能去更新
- **出口**：`login`、`register`、`room`、`invite-landing`、`invite-h5`（未装）、系统商店。

#### `invite-h5` 邀请落地（H5）

- **作用**：未装 App 的第一屏：说明、下载、把房间 ID 带过去。
- **元素**：应用标识；「有人给你留了一个房间」；「这个房间只住两个人」；「房间 ID 已带上，装好直接进」；下载按钮；已装，打开；脚注「一间房只有两个位置」。
- **状态**：有效 / 过期 / 已用 / 满员 / 缺房间 ID / 内置浏览器拦截（给「用浏览器打开」）。
- **出口**：应用商店；唤起 App → `invite-landing`；失效时无出口（不注册、不填表）。

#### `login` 登录

- **作用**：手机号 + 密码登录；用户名不能登录。
- **元素**：手机号；密码；登录；错误行；「没有账号，注册」；「忘记密码」；说明「单设备，新登录踢旧」。
- **状态**：空 / 输入中 / 手机号或密码不对（统一一句）/ 限流（5 次/小时）/ 网络失败 / 临时密码登录（→ 强制改密）/ 被踢下线。
- **出口**：`room`（按状态）、`register`、`forgot-password`、`invite-landing`（深链来源）。

#### `register` 注册

- **作用**：手机号（二次确认）+ 用户名 + 密码；注册完自动建房、直接进房。
- **元素**：手机号；再次输入手机号；用户名；密码；说明「手机号是编号、用户名是别名、不发验证码、不收证件」；协议勾选（用户协议 / 隐私政策）；注册；已有账号去登录。
- **状态**：格式错 / 两次不一致 / 手机号已注册 / 用户名重复 / 密码不足 8 位 / 网络失败 / 成功。
- **出口**：`room`（无邀请，自动建房）；`invite-landing`（有邀请）；`login`；`privacy`；`terms`。

#### `forgot-password` 忘记密码说明

- **作用**：讲清没有自助找回：用注册手机号发短信给运营者，人工核对后回临时密码。
- **元素**：说明；运营者号码（可拨）；短信内容「找回密码」；临时密码规则（8 位 / 24 小时 / 一次 / 登录后强制改密）；「不是这个号码发来的不处理」；「不是实时，通常 24 小时内」；回登录。
- **状态**：默认 / 已记下号码 / 找不回（注册号换了或卡丢了）/ 运营者号码未配置（不可用）。
- **出口**：`login`；`feedback`。

#### `invite-landing` 开房码页

- **作用**：第二个人在 App 内的一屏；房间 ID 由链接带入，只输 6 位开房码。
- **元素**：房间 ID（只读）；房主用户名；6 位开房码输入；进入按钮；错误行；脚注「一间房只有两个位置」；「码没带过来」时的重新打开链接。
- **状态**：未登录（先登录/注册，回来仍带 roomId）/ 待输码 / 码不对 / 限流（每账号每小时 5 次，超了锁 1 小时）/ 码对 → 直接进 `room` / 满员 / 过期 / 已用 / 我自己已有一间房（拦截，给「回我的房间」）。
- **出口**：`room`、`login`、`register`。

### 2.2 房间

#### `room` 房间（两个状态：正常 / 关门）

- **作用**：两人唯一的对话面；也是相册与我的的入口。
- **元素（正常态，从上到下）**：
  1. 房间头：我的入口；房间名「我们的房间」；相册入口。
  2. 对方关门状态条（`对方关着门` + 关门那句 + `你的消息会在对方开门时出现`）。
  3. 导出提示行（对方导出时出现一次，不可回复）。
  4. 消息流：日期分隔 / 气泡（0–28 天原文：文字、图片、语音）/ 日期行（第 28 天起替代气泡：`10 月 17 日 · 已收进相册`；留过的一天在留的当下就变成 `10 月 17 日 · 留过`，点开是那天的卡）/ 点（没照片的日子）/ 卡片（一张纸）/ 引用块（整段、可展开）/ 特别记忆折角 / 服务端时间 / 撤回（自己 2 分钟内）/ 失败态（`没发出去 · 重发`）。
  5. 上翻时的新消息提示（一个点 + `新消息`，不显示条数）。
  6. AI 问题（标「AI」，只在刚开门时，浮在输入框上方，不挡消息）。
  7. 门把手（输入框上沿）。
  8. 输入行：图片入口 / 麦克风 / 文字（2000 字）/ 发送。
  9. 卡片输入（刚开门后替代普通输入：1–2 句，最多 80 字）。
- **状态**：
  - 空（对方没进来）：`不用做什么` + `这儿还只有你`
  - 空（对方进来没说话）：`不用做什么`
  - 有消息：进来停在最新
  - 第 28 天：那一天收成一行 `已收进相册`
  - 留过的一天：聊天框只留一行 `留过`
  - 上翻历史：新消息不拽回底部
  - 发送中 / 已发送 / 失败 / 重发中
  - 图片上传中 / 失败（不重选图）
  - 语音录制中（按住、上滑取消、60 秒自动停）/ 上传中 / 失败
  - 引用态（输入框上方显示整段）
  - 半关（房间变暗，底部 `今晚到这儿` + `关` / `算了`，5 秒弹回）
  - 刚开门（排队消息按原时间出现 + AI 问题 + 卡片输入）
  - 对方关着门（消息照发，只有已发出）
  - 限流（`一次说太多了`，草稿保留）
  - 断线（不弹横幅，标失败）/ 重连补拉
  - 首次进房的通知权限说明（弹 `notify-ask`）
- **关门态**：房间暗；只剩关门那句 + `门口有一张卡片`（若有）+ 顶部把手；输入框一行 `说一句，门就开`；看不到任何消息；不能发普通消息。
- **出口**：`album`、`me`、`image-viewer`、`message-actions`、`invite-share`、`room-code-setup`、`day-card`（点短记/点/引用块）。

#### `room-code-setup` 设置开房码

- **作用**：房主设 6 位开房码；没码不能邀请。
- **元素**：说明（只有知道码的人能进；满 2 人失效；可改）；6 位数字输入；确认；提示「别用 123456、生日、手机尾号」。
- **状态**：未设 / 已设（显示当前码 + 改）/ 改码中（旧码立刻失效）/ 格式不合格 / 码太简单（只提示，不拦）/ 保存失败。
- **出口**：`invite-share`、`room`。

#### `invite-share` 邀请与开房码（弹层）

- **元素**：房间 ID；开房码明文；邀请链接；系统分享；改开房码；说明「满 2 人后链接与码一起失效」。
- **状态**：未设码（先去设）/ 已设 / 已满员（不可分享）。
- **出口**：`room-code-setup`；系统分享；关闭 → `room`。

#### `leave-room` 离开房间（弹层，钩子）

- **状态**：本版不做。入口在 `me`；点开后只有一句「离开房间还没定」+ 返回。离开之后房间是什么样（留房期、只读相册、能不能回来）随结束态一起定，见 PRD §13。
- **出口**：`me`。

#### `new-room` 开始新的房间（本版不做）

- **状态**：留档不实现；等结束态定了再补。

#### `message-actions` 长按菜单（弹层）

- **元素**：`引用并回复`；`特别记忆`；关闭。
- **状态**：文字 / 图片 / 语音 / 卡片（只可引用）/ 短记行与点（无菜单）/ 已撤回的引用块（无菜单）。
- **出口**：`room`（引用态）；`room`（标记成功，出现折角）。

#### `image-viewer` 看图（弹层）

- **元素**：图片（原图或缩略图）；一行说明（服务端时间 / 相册日期）；`留` 或 `已留`（从聊天进）；`从我这边隐藏`（从相册进）；关闭。
- **状态**：原图可放大 / 缩略图不可放大 / 加载中 / 加载失败重试 / 已留 / 已隐藏。
- **出口**：关闭 → 来源页；`keep-day`；`hide-day`。

### 2.3 相册

#### `album` 相册

- **元素**：标题「相册」；当前年月 + 前后翻；星期行；月历格子（四态：留过=原图缩略+日期 / 没留有照片=缩略图+日期 / 没留没照片=点+日期 / 空）；「隐藏的一天」入口；空态。
- **状态**：有内容 / 这个月还没有 / 整个相册还没有留下什么 / 第 7 天起某天进相册 / 28 天后定型。
- **出口**：`day-card`；`album-hidden`；返回 → `room`。

#### `day-card` 一天的卡

- **元素**：日期；AI 图文卡文字（一段话，不可改，标「AI 整理」；写法本版不细化）；照片网格（三列，最多 9 张，多的收起来；留过=原图，没留=缩略图且不可放大）；**此刻**（0–2 条，一条一行，带用户名，只有本人能改删；唯一入口在这里）；最后的小框（特别记忆原话，一行一个，可叠；标它的人可删）；`看那天的原文`（留过才有）；`留过` / `留这一天`；`隐藏这一天`。
- **状态**：留过 / 没留有照片 / 没留没照片（只有点） / 有卡 / 卡生成失败 / 28 天内可留 / 28 天后留的入口关闭、但「此刻」仍可写 / 已隐藏 / 小框可删或不可删 / 此刻为空、一条、两条、编辑中。
- **出口**：`day-originals`、`keep-day`、`hide-day`、`delete-mark`、`image-viewer`；行内编辑/删除此刻；返回 → `album`。

#### `day-originals` 那天的原文

- **作用**：留过的一天，原文永久保留；只读，不在聊天框。
- **元素**：日期；消息列表（服务端时间 + 内容 + 图片原图 + 语音）；没有输入框；没有引用/撤回/长按菜单；返回。
- **状态**：加载中 / 加载失败重试 / 语音文件缺失（只显示时长）/ 空（不应发生）。
- **出口**：返回 → `day-card`。

#### `keep-day` 留这一天确认（弹层）

- **元素**：`留下就是永久`；`相册是你们两个人共同的内容`；`之后只能从我这边隐藏，不能单方删除`；`再想想`；`留`。
- **状态**：确认中 / 成功（冻结、保原图、原文搬进卡、聊天框只留一行 `留过`）/ 失败 / 28 天后入口关闭。
- **出口**：`day-card`；关闭 → 来源页。

#### `hide-day` 隐藏这一天（弹层）

- **元素**：`只在我的相册里不显示，对方照常可见`；`隐藏`；`取消`；已隐藏时的 `取消隐藏`。
- **状态**：可隐藏 / 已隐藏。
- **出口**：`album`；`day-card`。

#### `delete-mark` 删小框（弹层）

- **元素**：`删了只在我这边少一条，对方仍看到`；`如果这天已经定型，删了就真没了`；`删除`；`取消`。
- **状态**：28 天内（原消息还在）/ 28 天后（定型）/ 不是我标的（不可删，不出现）。
- **出口**：`day-card`。

#### `album-hidden` 隐藏的一天

- **元素**：标题；说明「隐藏的天不在日历上出现，内容还在」；列表（日期、短记首段、照片数、恢复）；空态。
- **状态**：列表 / 空 / 恢复中 / 失败。
- **出口**：恢复 → `album`；返回 → `album`。

### 2.4 我的与设置

#### `me` 我的

- **元素**：标题；资料卡（用户名 + `和 XX 在同一个房间`）；卡一（账号与安全 / 通知）；卡二（导出 / 这个房间怎么运转 / 离开房间）；底栏（隐私政策 / 用户协议 / 版本号 / 反馈）；底部一句 `话会收起来，照片可以留下`。
- **状态**：有房（2 人）/ 单人（对方没来）/ 注销冷却中（顶部一行可撤销）。
- **出口**：`profile`、`account-security`、`notifications`、`export`、`how-it-works`、`leave-room`、`privacy`、`terms`、`feedback`；返回 → `room`。

#### `profile` 个人资料

- **元素**：用户名（可改）；手机号（打码）；房间（房间 ID、对方用户名）；加入时间；邀请（未满时）。
- **状态**：查看 / 改名中 / 未满 / 已满。
- **出口**：`rename`、`invite-share`、`account-security`；返回 → `me`。

#### `rename` 改用户名（弹层）

- **元素**：输入（1–12 字）；保存；取消；错误行「这个名字房间里已经有人用了」。
- **状态**：空 / 重复 / 保存中 / 成功（对方界面立刻变）。
- **出口**：`profile`。

#### `account-security` 账号与安全

- **元素**：手机号（打码）；修改密码；换手机号；退出登录；注销账号（最底）；说明「退出登录不等于离开房间」。
- **状态**：正常 / 注销冷却中 / 敏感操作要求密码。
- **出口**：`change-password`、`phone-change`、`logout-confirm`、`account-delete`；返回 → `me`。

#### `change-password` 修改密码

- **元素**：当前密码；新密码（≥ 8 位）；说明「改完其他设备掉线，本机保持」；提交；忘记当前密码。
- **状态**：普通 / 强制改密（临时密码登录后，不能跳过）/ 旧密码错 / 新密码不合规 / 两次不一致 / 限流 / 成功。
- **出口**：`account-security`；`room`（强制改密完成）；`forgot-password`。

#### `phone-change` 换手机号

- **元素**：新手机号；再次输入；密码；说明「没有短信验证，无法验证新号归属」「换号后旧号可再注册」；提交。
- **状态**：格式错 / 两次不一致 / 密码错 / 新号已注册 / 成功 / 限流（1 次/天）。
- **出口**：`account-security`。

#### `logout-confirm` 退出登录确认（弹层）

- **元素**：`退出后，重新登录会回到这间房`；`退出`；`取消`。
- **状态**：确认中 / 成功 → `login`。
- **出口**：`login`；关闭。

#### `account-delete` 注销账号

- **元素**：三条说明（7 天冷却 / 共同相册只读留给对方 / 期间登录可撤销）；密码；输入「注销」；提交；冷却期内撤销入口。
- **状态**：未提交 / 密码错 / 确认字不对 / 已提交（冷却中）/ 已执行。
- **出口**：`account-security`；`login`（执行后）；撤销 → `account-security`。

#### `notifications` 通知设置

- **元素**：系统权限状态 + 去设置；说明「只推新消息和一张卡片」；新消息开关；锁屏显示内容开关（默认关）+ 打开后一行提示；说明「不做图标角标」；今晚不提醒开关（到明早 8:00）；说明「只是不响，消息照常进」。
- **状态**：权限开 / 未开 / 被拒 / 总开关关 / 锁屏内容开/关 / 今晚不提醒生效中 / 离线。
- **出口**：系统设置；返回 → `me`。

#### `notify-ask` 通知权限说明（弹层）

- **元素**：`有人说话时，通知你。别的不会推。`；`允许`；`先不用`；说明「拒绝后不再反复弹」。
- **状态**：未决定 / 已允许 / 已拒绝 / 系统层面被拒。
- **出口**：关闭 → `room`。

#### `export` 导出

- **元素**：范围（全部 / 近 30 天 / 近 7 天）；格式（PDF 纪念册 / 纯文本）；生成；说明（本人副本、原图一并打包、对方收到一条提示、链接 7 天）；成功行。
- **状态**：未选 / 生成中 / 成功 / 失败重试 / 链接过期 / 没有可导出内容。
- **出口**：系统分享 / 保存；返回 → `me`。

#### `how-it-works` 这个房间怎么运转

- **元素**：四段——记忆（一周后收成图文卡、四周定型；没照片只剩点；留过保原图）；AI（每 7 天读一次、只用于压缩、不留存不训练、可关）；停（关门真的收不到、开门要写卡片）；想聊（只在开门时、AI 问一句、没有复述）；「怎么关掉」留空位。
- **状态**：默认 / AI 关闭（说明随之改变）/ 离线（静态文本可读）。
- **出口**：返回 → 来源页。

#### `privacy` 隐私政策

- **元素**：正文（手机号必存、密码哈希、不存证件与真名；消息 28 天压缩、第 28 天删原文；AI 读什么；忘密码只能人工重置）；版本与生效日期。
- **状态**：加载中 / 失败重试 / 离线。
- **出口**：返回 → 来源页。

#### `terms` 用户协议

- **元素**：正文；版本与生效日期。
- **状态**：加载中 / 失败重试。
- **出口**：返回 → 来源页。

#### `feedback` 反馈

- **元素**：邮箱；运营者手机号（可拨）；说明「不提供在线客服与工单」。
- **状态**：默认 / 已拨打。
- **出口**：返回 → 来源页。

## 3. 关键流程

1. **首装无邀请**：`launch` → `register` → 自动建房 → `room`（单人）→ `room-code-setup` → `invite-share`。
2. **已装 App 的邀请**：链接 → `invite-landing` → 未登录则 `login`/`register`（保留 roomId）→ 输码 → 直接进 `room`。
3. **未装 App 的邀请**：`invite-h5` → 商店 → 首次打开 → `invite-landing` → 注册/登录 → 输码 → 进房。
4. **发消息**：输入 → 发送中（气泡先出现、不显示时间）→ 已发送（服务端时间）；失败重试 2 次 → `没发出去 · 重发`。
5. **引用与撤回**：长按 → `引用并回复` → 整段引用条 → 发出 → 引用块按 id 实时渲染；撤回后引用显示「原消息已撤回」。
6. **记忆**：第 7 天起，日历里生成那天的卡，每 7 天压一次；房间保留原文到第 28 天，之后只留一行日期；留过的一天在留的当下收走原文，从卡里「看那天的原文」。
7. **留一天**：`album` → `day-card` → `keep-day` → 原图 + 短记冻结、不再压缩。
8. **特别记忆**：长按 → `特别记忆` → 这句保原话 / 这张保缩略图；28 天后不删不缩；谁标谁删。
9. **关门**：房间上拉把手 → 半关（`今晚到这儿` 不能空 + `关` / `算了`）→ `关` → 关门态（收不到、不能发）→ `想聊`（AI 问一句 + 写卡片）→ 开门；或对方用门口卡片开门。
10. **通知**：消息合并成一条带数字；点开落到消息 / 短记 / 一天的卡；门关着先显示门。
11. **离开房间**：`me` → `leave-room`（钩子）；本版不做离开之后的房间状态。
12. **账号**：`account-security` → 改密（踢其他设备）/ 换号（房间相册不变）/ 退出（回 `login`，房间不变）/ 注销（7 天冷却，相册只读留给对方）。

## 4. 全局状态矩阵

| 状态 | 出现在 | 表现 | 可去哪 |
|---|---|---|---|
| 未登录 | 任何受保护页 | 跳 `login`，记住目标 | 登录后回目标 |
| 离线 | 房间、相册、我的、导出 | 只读可看；写操作标失败 | 重试 |
| 通知权限被拒 | `room`、`notifications` | 页内一行说明 + 去系统设置 | 系统设置 |
| 麦克风/相册权限被拒 | `room` 语音/图片、`export` | 页内说明 + 去系统设置 | 系统设置 |
| 发送失败 | `room` | `没发出去 · 重发` | 重发 |
| 消息被撤回 | `room`、引用块、通知 | 消失 / `原消息已撤回` | 房间 |
| 消息压缩 | `room` | 气泡 → 灰字 → 点 | 点 → `day-card` |
| 门关着 | `room` | 关门态；无消息 | 写卡片 / 取门口卡片 |
| 门口有卡片 | `room` 关门态 | `门口有一张卡片` | 用卡片开门 |
| 注销冷却 | `me`、`account-security` | 顶部一行可撤销 | 撤销 |
| 深链失效 | `invite-h5`、`invite-landing` | 事实 + 一条出路 | 回登录 / 我的房间 |
| 版本过低 | `launch` | 只能更新 | 商店 |

## 6. 给实现方的约束

1. **不要设计视觉**：颜色、字体、间距、圆角、图标、动效一律不实现，等设计稿。
2. **页面 id 即路由名**；状态用同一路由的子状态（`room` 的 `closed` / `hold`），不要拆成三个路由。
3. **弹层不叠弹层**；同一时间只允许一层。
4. **房间是根**：相册与我的都从房间进，返回都回房间。
5. **所有空态、错误、加载都要有**：不要只做成功路径。
6. **不要把「未定义」自行补全**：遇到 §5 的条目，先停下来问。
7. **文案以 PRD 为准**；本文件里的中文引号内容是界面文案，不要改写。
8. **不做**：Tab 栏、头像、搜索、转发、复制、已读、送达、输入中、角标、说给自己。
