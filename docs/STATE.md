## 一、产品是什么

**一个会忘的房间，一个不会忘的相册。**
话会收起来，照片可以留下。

- **房间**：只有两个人；原文留 21 天，之后收进图文卡；没有已读、在线、正在输入。
- **相册**：按天的记忆日历；留过保原图，没留保缩略图，没照片只剩一个点。
- **门**：停是关门（真的收不到）；想聊是开门（写一张卡片）。
- **原则**：给两个人一个地方，不给一套方法；这扇门没有猫眼。

四条规则（`VISION.md`）：话会收起来 / 停不需要同意 / 想聊只在停过之后 / 要留的自己按。

## 三、已定（摘要）

- **账号**：手机号=唯一编号；用户名=别名；密码；无恢复码、无短信、无实名
- **准入**：一账号一房；**房间码就一个**（6 位字母数字，链接里也用它）——建房即生成，输对就进；房间 2 人；房间名两人都能改；离开房间只在「我的」留入口（钩子）
- **找回**：用注册手机号发短信给运营者 → 人工核对 → 临时密码（8 位/24h/一次/强制改密）
- **房间**：文字 2000 / 图片一张 / 语音 60s；发送四态；seq 补拉；服务端时间；引用整段（可取消）；撤回 2 分钟；无已读/送达/输入中
- **记忆**：原文留 21 天（**按天切**）；第 1 天起卡进相册、第 7、14、21 天各压一次；21 天后原文变一行日期；留一天 = 原文搬进卡 + 原图；卡 = AI 图文 + 此刻；**每天都有卡，只是内容不同**（纯文字 / 只有一行事实）；写法与压缩交给单独算法
- **相册**：按月的相册；缩略图与原图双层；一天的卡 + 最后的小框；隐藏一天；小框谁标谁删
- **门**：停=关门（收不到、半关确认；半关**不自动弹回**，那句要现写、不能空）；想聊=开门（AI 问一句、写卡片、卡片是钥匙；递卡前不显示排队消息）
- **通知**：只推新消息（卡片是消息流里的一条，跟着合并走）；合并成一条带数字；锁屏默认无内容；无图标角标；今晚不提醒到 8:00
- **我的**：两组卡片 + 居中底栏；账号与安全 / 通知 / 导出 / 运转说明 / 离开房间（钩子）
- **说给自己**：已删除
