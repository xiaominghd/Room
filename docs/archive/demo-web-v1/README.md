# 房间 · 本地 Demo

一个能点的原型，用来验证 v2.0 的五条规则：**话七天消散 / 停 / 想聊 / 留照片 / 说给自己**。

## 打开

已经起了一个本地服务：

**http://127.0.0.1:8123**

也可以直接双击 `index.html`（部分浏览器会限制 `file://` 的 localStorage，用上面的地址更稳）。

## 建议按这个顺序试

1. **切 A / B**：右上角切换视角，看两个人在同一间屋子里的样子。
2. **停**：A 按「停」，切到 B 发一条消息，再切回 A——房间是暗的，但 B 的消息在。A 发一句，房间亮。
3. **想聊**：A 按「想聊」，切到 B 按；两个人按了才出问题。各答一句，看 AI 复述；时间旅行 +1 天，看「24 小时 · 未成」。
4. **留照片**：在「便利店的关东煮」那张点「留」，先出一张确认卡（永久 / 共同内容 / 只能从我这边隐藏），确认后才进相册；时间旅行 +7 天——聊天没了，照片还在。
5. **说给自己**：输入框切到「给自己」，写一句，点「抽屉」看它。
6. **时间旅行 +7 天**：看消息变成「日期 · 条数」的灰痕。
7. **我的**：点右上角绿色小门——通知开关、导出、恢复码、这个房间怎么运转。
8. **邀请码**：从「我的」底部的「演示：邀请码」进（产品里是第二个人第一次进来的屏）。
9. **启动页**：刷新时会闪一下「房间」启动页，点一下可跳过。

## 两套视觉并存

- 「我的 / 邀请码 / 个人资料 / 导出 / 恢复码 / 这个房间怎么运转 / 留图确认 / 启动页」按 `未命名画布.kui.fig` 实现：冷白底、白卡片、鼠尾草绿。
- 房间与相册仍是之前那版暖白陶土，**还没有统一**。

## 这是 demo，不是产品

- 没有后端，状态存在浏览器的 localStorage 里；换浏览器/清缓存就重来。
- 照片是渐变占位，不是真图；AI 复述是写死的演示逻辑；语音没做。
- 「导出」「复制恢复码」「更换资料」只给反馈，没有真功能。
- 不验证：推送、安装、真机手感、多设备。

## 文件

- `index.html` —— 结构
- `styles.css` —— 样式
- `app.js` —— 状态、渲染、交互
- `_smoke.js` —— 一次性冒烟测试：`node _smoke.js`
- `未命名画布.kui.fig` —— 设计稿原件（fig-kiwie 导出，ZIP 容器，含画布数据与素材）
