# V3 · B 组：房间的边角

> 范围：消息流本身——灰痕、撤回、失败重发、滚动、时间、键盘、图片、语音。
> 约定：只写 PRD，不动前端。

---

## 0. 目标

打开房间，**不需要理解任何规则就能用**：
往上翻是历史，往下是新的；发出去就是发出去了，没发出去会告诉你；话没了会留一道痕；翻到哪儿就是哪儿，不被拽回底部。

---

## 1. 消息流

### 1.1 结构（从上到下）

```
日期分隔        今天 / 昨天 / 10 月 17 日
消散灰痕        10 月 9 日 · 3 条
消息            对方白气泡 / 自己蓝气泡
    时间        18:20
消息
    ...
```

- 日期分隔：只在跨天时出现一次，居中，11px，上下 8
- 灰痕：出现在它那一天的位置，**在当天还活着的消息之前**
- 消息间距 10；跨天时先插日期分隔

### 1.2 灰痕

| 项 | 规则 |
|---|---|
| 形态 | 44px 横线 + 3×8 小方块 + 文案 + 小方块 + 横线 |
| 文案 | `10 月 9 日 · 3 条`，只有日期与条数 |
| 聚合 | 同一天到期的消息合成一条；不同天各一条 |
| 位置 | 按到期消息**原本的日期**排，不按清理时间排 |
| 点击 | 无 |
| 长按 | 无 |

不出现：「已消散」「暂无消息」「消息已过期」。

### 1.3 空态

- 只在**既没有消息、也没有灰痕**时出现
- 有灰痕就不是空态（房间有历史，只是话没了）
- 文案：`不用做什么` +（对方没进来时）`这儿还只有你`

### 1.4 滚动

- 进入房间：直接停在最新一条
- 用户在往上翻：**不自动回底**
- 新消息到达：用户在底部就跟随；不在底部就不跳，底部浮一个小提示（一个点 + `新消息`），点一下回到底部
- 从后台回来：保持离开时的位置

---

## 2. 一条消息

### 2.1 文字

| 项 | 规则 |
|---|---|
| 最大宽度 | 屏幕的 78% |
| 圆角 | 16；对方左上 4，自己右上 4 |
| 内边距 | 12 / 10 |
| 字号 | 15 / 行高 22 |
| 换行 | 正常换行，不裁切、不省略 |
| 连续消息 | 各自独立成条，时间在每条下面（设计稿如此） |

### 2.2 图片

| 项 | 规则 |
|---|---|
| 聊天里 | 220 × 164，圆角 12，居中裁切 |
| 发送前 | 长边压到 1600，保留原图另存为后续选项 |
| 说明 | 图下一行 `10 月 17 日 18:31 家里的窗台` |
| 留 | 图卡右下「留」；已留显示「已留」，不可再点 |
| 点开 | P1：全屏查看，右上「留」 |
| 七天后 | 随消息消失；已留的在相册里还在 |

### 2.3 语音

| 项 | 规则 |
|---|---|
| 上限 | 60 秒，到 60 秒自动发送 |
| 录制 | 按住录，上滑取消，松手发送 |
| 显示 | 播放键 + 波形 + `0:12` |
| 播放 | 点一下播放/停止；同时只播一条 |
| 转文字 | 不做 |

### 2.4 时间与状态

- 每条消息下 11px 灰色时间
- 自己消息 2 分钟内：时间左边出现「撤回」
- 发送中：气泡右下 40% 透明度的小圆点
- 失败：时间位置变成 `没发出去 · 重发`（可点）
- 已发送：只显示时间，不加「已读」「已送达」

---

## 3. 撤回

- 只有自己 2 分钟内的消息能撤回
- 点击即撤，**不要二次确认**（2 分钟本来就是后悔窗口，再确认一次就超时了）
- 撤回后：消息**完全消失**，不留「撤回了一条」这类痕迹
- 发送者看到 toast：`撤回了`
- 对方那边直接消失；如果正好看着屏幕，让它淡出 120ms，不要硬闪
- 撤回不产生灰痕、不进导出
- 被引用过的消息撤回后，引用块显示「原消息已撤回」，不显示内容

**为什么不留痕**：留一行「对方撤回了一条」，等于把「他撤回了什么」变成一个可以追问的证据。这个产品不把话变成证据。

---

## 4. 发送失败与重试

| 场景 | 处理 |
|---|---|
| 发送中 | 气泡正常显示，右下小圆点 |
| 自动重试 | 失败后 2 秒、8 秒各重试一次 |
| 仍失败 | 时间位置变 `没发出去 · 重发` |
| 手动重发 | 点一下重发同一条，不复制内容 |
| 断网 | 不弹全局横幅；只在气泡上标失败 |
| 恢复网络 | 不自动补发（用户自己点重发），避免突然连发一串 |

不做：全局「网络异常」弹窗、失败队列页面、红点。

---

## 5. 键盘与输入

- 键盘弹起：输入框跟随，最新一条不被遮
- iOS：`KeyboardAvoidingView` padding；Android：`adjustResize`
- 输入框最多长到 4 行，超出内部滚动
- 发送后键盘不收起（连续说话）
- 发送后清空输入框；发送失败时草稿保留

---

## 6. 时间显示

| 位置 | 规则 |
|---|---|
| 日期分隔 | 今天 → `今天`；昨天 → `昨天`；更早 → `10 月 17 日`；跨年 → `2025 年 10 月 17 日` |
| 每条消息 | `18:20`；不显示「刚刚」「1 分钟前」这类相对时间 |
| 同一分钟 | 照常显示，不去重 |

不用相对时间，是因为「刚刚」会变，而这个房间里的东西不该一直在变。

---

## 7. 验收

- [ ] 七天前的话消失，原地一条灰痕；同一天的多条合成一条
- [ ] 有灰痕时不显示空态
- [ ] 撤回后消息完全消失，对方侧淡出，不出现「撤回了一条」
- [ ] 断网发送：标「没发出去 · 重发」，恢复后点一下能发出去
- [ ] 往上翻历史时，新消息来了不跳
- [ ] 键盘弹起，最新一条仍可见
- [ ] 长消息换行不裁切，宽度不超过 78%
- [ ] 图片七天后消失，已留的还在相册
- [ ] 语音到 60 秒自动发送，上滑能取消
