# V3 · 通知

> 属于 PRD，不动前端。
> 一句话：**只推新消息；其他都不推；锁屏默认不显示内容。**

---

## 1. 推什么、不推什么

| 事件 | 推不推 | 说明 |
|---|---|---|
| 新消息（文字 / 图片 / 语音） | ✅ | 只推这个 |
| 一张卡片（想聊开门递的） | ✅ | 标题写「一张卡片」，不写内容 |
| 停 / 关门 | ❌ | 不推；对方下次打开才看到 |
| 想聊（单人按） | ❌ | 不推，只留一个状态 |
| 门开了 / 卡片被取走 | ❌ | 不做回执 |
| 导出 | ❌ | 只在 App 内提示 |
| 结束 / 留房期 | ❌ | 不推 |
| 已读 / 送达 / 正在输入 | ❌ | 不存在 |

**只有两件事值得把人叫回来：有人说了话，或有人递了一张卡片。**

---

## 2. 内容与隐私

| 设置 | 默认 | 行为 |
|---|---|---|
| 锁屏显示内容 | **关** | 通知只写「有新消息」 |
| 打开后 | — | 显示发信人别名 + 消息内容；设置页要写清代价 |

- 图片 / 语音：即使打开内容，也只写「一张照片」「一段语音」，不显示缩略图、不自动播放
- 通知标题：`我们的房间`
- 通知正文（默认）：`有新消息`
- 卡片通知：`有一张卡片`

---

## 3. 合并（App 没打开时）

- 同一房间**只保留一条消息通知**
- 第一条：正常弹出、响一声
- 后面的：更新同一条，**不再响**，在正文后面加一个小数字：

```
我们的房间
有新消息 3
```

- 数字 = 自上次打开房间以来的新消息条数；进房间后清零
- 超过 99 显示 `99+`
- 打开内容时：`栗子：今天风好大… 3`
- 不写「你错过了 3 条」——数字只是跟在正文后面，不加句子
- **卡片单独一条**，不并进消息数字里；同一房间最多两条通知（消息一条、卡片一条）

## 4. 关门期间

- 关门的人：**完全不推**（这是关门的定义）
- 对方：照常推自己的新消息
- 门口的卡片：不推；等他开门时看到
- 关门这个动作本身：不推给对方

---

## 5. 点通知落到哪

| 消息的状态 | 点开之后 |
|---|---|
| 还在 | 进房间，滚到那一条 |
| 已经压缩进短记 | 进房间，滚到那天的短记 |
| 已经定型 | 进相册，打开那天的卡 / 点 |
| 已被撤回 | 进房间，不滚；那一条不存在了 |

- 如果房间在关门状态：先显示门，不硬滚
- 不弹「消息已过期」这类提示

---

## 6. 什么时候要权限

- 进房之后、发第一条消息之前
- 一句人话：`有人说话时，通知你。别的不会推。`
- 拒绝之后：不反复弹；在「我的 → 通知」里留一个入口

---

## 7. 静音

- 「今晚不提醒」：到第二天 8:00 自动恢复
- 它不是「停」：房间照常，消息照常进，只是不响
- 放在「我的 → 通知」里，不放在房间头部
- 不做「免打扰时段」这种复杂设置

---

## 8. 角标

**不做 App 图标角标。**

- 红色数字会催人；这个产品不催
- 数字只出现在通知横幅的正文后面（`有新消息 3`）
- 想看的时候打开，不想看的时候它不叫你

---

## 9. 失效通知

- App 打开时，清理已经不在的消息对应的通知
- 被撤回的消息：立刻清掉它的通知
- 不在通知栏留「一条已经不存在的话」

---

## 10. 文案

| 场景 | 文案 |
|---|---|
| 默认新消息 | `我们的房间` / `有新消息` |
| 卡片 | `我们的房间` / `有一张卡片` |
| 打开内容后 | `我们的房间` / `栗子：今天风好大…` |
| 权限说明 | `有人说话时，通知你。别的不会推。` |
| 静音 | `今晚不提醒` |
| 静音中 | `明早 8:00 恢复` |

---

## 11. 已定

| # | 问题 | 决定 |
|---|---|---|
| 1 | 多条消息 | 合并成一条通知，正文后加数字；只响第一声 |
| 2 | 数字口径 | 自上次进房间以来的新消息数；进房间清零；99+ |
| 3 | 锁屏内容 | 默认关；可在设置里打开，打开时写明代价 |
| 4 | App 图标角标 | 不做；数字只在通知横幅上 |
| 5 | 权限时机 | 进房后、发第一条消息之前 |
| 6 | 今晚不提醒 | 做，到第二天 8:00 |
| 7 | 卡片通知 | 推，单独一条，只写「有一张卡片」 |
| 8 | App 打开时的提示 | 在底部就跟随；不在底部浮一个点 +「新消息」，不显示条数 |

## 12. 验收

- 只推新消息和卡片；停、想聊、导出、结束都不推
- 锁屏默认看不到内容；打开后有明确提示
- 连发 10 条：只有一条通知，正文后显示 10，只响第一声；进房间后数字清零
- 关门期间，关门的人一次都不响
- 点通知能落到那条消息；消息没了就落到短记或那天的卡
- 没有 App 图标角标；数字只在通知横幅上
