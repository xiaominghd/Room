## 2. 账号与安全

```
手机号        138****0000        →
修改密码                         →
退出登录                         →
注销账号                         →   （最底，红字，不藏）
```

### 2.1 换手机号

- 字段：新手机号（二次确认）+ 密码
- 没有短信，无法验证新号归属；这是已知风险
- 成功后旧号释放；房间、相册、留房期都不变
- 页面写明：`换号后，旧号可以再注册新账号`

### 2.2 修改密码

- 旧密码 + 新密码（≥ 8 位）
- 成功后踢掉其他设备，本机保持登录

### 2.3 退出登录

- 一次确认：`退出后，重新登录会回到这间房。`
- 清本机 token

### 2.4 注销账号

- 说明三件事：7 天冷却、共同相册只读留给对方、期间登录可撤销
- 需要：密码 + 输入「注销」
- 7 天后执行；执行后身份与登录删除，相册对对方仍可见

## 3. 通知

```
新消息通知          [开关]
锁屏显示内容        [开关，默认关]
今晚不提醒          [开关，到明早 8:00]
```

- 关掉总开关：不推送；App 内照常收到
- 打开锁屏内容：下方出现一行提示 `锁屏上会看到消息内容`
- 今晚不提醒：打开后显示 `明早 8:00 恢复`
- 不做免打扰时段、不做声音选择（交给系统）

---

## 4. 导出

```
范围    [全部] [近 30 天] [近 7 天]
格式    PDF 纪念册 / 纯文本
        [生成导出文件]
```

- 导出的是本人副本，照片原图一并打包
- 导出时对方收到一条提示（不推送）
- 链接 7 天有效；过期后重新生成
- 只含消息与照片；不含任何本机数据

## 5. 这个房间怎么运转

按新规则重写，四段：

| 段 | 内容 |
|---|---|
| 记忆 | 消息会在四周内变短，四周后只剩一个画面和一个点；留过的保原图 |
| AI | 每 7 天读一次上一周的话，只用来压缩；不留存、不训练 |
| 停 | 关门，真的收不到；开门要写一张卡片 |
| 想聊 | 只在开门时发生；AI 问一句，没有复述 |

- 「怎么关掉」这一段等“结束”定了再补；现在写：`还没想好怎么结束，先不写。`（不出现这句，留空位）
- 不在这一页解释压缩比例、缩略图这些机制

## 6. 底栏与杂项

| 项 | 形态 | 内容 |
|---|---|---|
| 隐私政策 | App 内静态页 | 存什么、存多久、AI 读什么、怎么关 |
| 用户协议 | App 内静态页 | 简短，不写长条款 |
| 版本号 | 一行小字 | `v1.0.0`，不做连点进调试 |
| 反馈 | 页面 | 邮箱 + 运营者手机号（找回密码那个号） |

隐私政策里要写清：手机号必存（登录）、AI 每 7 天读一次用于压缩、找不到密码只能人工重置。

## 9. 验收

- 我的页两组卡片 + 底栏，没有恢复码、没有演示入口
- 一级没有开关，点进去才有
- 换号后房间、相册不变
- 注销 7 天内可撤销，执行后相册对对方可见
- 通知关闭后 App 内照常收消息
- 运转说明和现在的记忆规则一致（不是“七天消失”）
