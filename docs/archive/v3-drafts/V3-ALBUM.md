# V3 · 相册：活的记忆日历

> 属于 PRD，不动前端。
> 相册不是“留的照片”，是**每天一张卡**：短记 + 照片 + 你亲手留下的小框。

---

## 0. 一句话

**没留的一天，也有一个画面、一句话；留过的一天，画面是原图，还多一个你写下的小框。**

---

## 1. 两种留

| | 在哪留 | 留什么 | 后果 | 谁能删 |
|---|---|---|---|---|
| **留一天**（主） | 相册里点「留这一天」 | 原图 + 短记 | 这一天冻结；共同内容 | 只能隐藏 |
| **留一句 / 留一张**（特别记忆） | 聊天里长按 | 这句话保原话；这张照片保缩略图并置顶 | 整天仍压缩，但这句不被删、不缩短 | **谁标的谁删** |

- 留一天是承诺；留一句是给这句话加权重。
- 两种都可以在 28 天内做；28 天之后，原话和原图都没了，不能再留。

---

## 2. 月历格子

| 那天的状态 | 格子里 |
|---|---|
| 留过 | 清晰的原图缩略 + 日期 |
| 没留、有照片 | 略柔的缩略图 + 日期（点了不能放大） |
| 没留、没照片、有短记 | 一个小圆点 + 日期 |
| 什么都没有 | 空 |

- 只显示有内容的月份；可以一直往回翻
- 不做“那年今日”、不做搜索、不做统计

---

## 3. 一天的卡

```
┌─────────────────────────────┐
│ 10 月 17 日                  │
│                             │
│ 那天下了雨，他在便利店门口    │  ← AI 短记
│ 分了你一串关东煮。            │
│                             │
│ [缩略图] [缩略图] [缩略图]    │  ← 照片：留过是原图，没留是缩略图
│                             │
│ ┌─────────────────────┐     │
│ │ 「你先吃，我不饿」     │     │  ← 特别记忆：原话，小框，放在最后
│ └─────────────────────┘     │
│                             │
│ 留过 / 留这一天              │
└─────────────────────────────┘
```

- **小框永远放在最后**，不打断短记和照片
- 小框里是原话，不加引号、不加“谁留的”
- 多个小框就叠着放，一行一个
- 标记（比如一个很小的折角）只表示“这是留过的”，不表示谁留的
- 小框可以被标它的人删掉；删了只在我这边少一条，对方仍看到，也不影响这一天

---

## 4. 留的位置

| 入口 | 做什么 |
|---|---|
| 相册某一天 → 「留这一天」 | 主入口；原图 + 短记冻结 |
| 聊天长按一条 → 「特别记忆」 | 保这一句原话 / 这一张缩略图 |
| 第 28 天之后 | 两个入口都关闭 |

---

## 5. 隐藏与删除

| 动作 | 范围 | 谁能做 | 对方看到什么 |
|---|---|---|---|
| 隐藏一天 | 只影响自己 | 任何一方 | 照常可见 |
| 删除小框 | 只影响“特别记忆”这一条 | **标它的人** | 照常可见（只在我这边少一条） |
| 删除一天 | 不做 | — | — |
| 删除照片 | 不做 | — | — |

**小框删除的语义**：删的是“我给它加的那点重量”，不是删对方说过的话。
如果那天还没定型，原消息还在；如果已经定型，删了就真没了。

---

## 6. 压缩怎么对待标记

- AI 删无关句时，**被标记的句子一律不删**
- 被标记的句子**不参与缩短**，原话保留
- 被标记的照片置顶，并保留缩略图
- 没标记的照片：第 28 天也保留缩略图（默认记忆）
- 短记不写争执；一天只有吵架，就留空，只留一个点
- 小框不随短记一起变短；它只在定型时定稿

---

## 7. 空态

- 这个月没有内容：`这个月还没有`
- 整个相册没有内容：`还没有留下什么`
- 不写“暂无照片”、不写“已消散”

---

## 8. 已定

| # | 问题 | 决定 |
|---|---|---|
| 1 | 一天多张照片怎么排 | 三列网格，最多 9 张，多的收起来 |
| 2 | 没留的照片能不能放大 | 不能：缩略图就是记忆 |
| 3 | 删小框后对方那边也少一条吗 | 不：只在我这边少，对方仍看到 |
| 4 | 留过的一天，28 天内能不能再补小框 | 能 |
| 5 | 相册入口 | 只从房间进，不在「我的」里再放一个 |

## 9. 验收

- 第 7 天：这一天进相册，有短记
- 没留的一天：第 28 天后有缩略图 + 短记（或一个点）
- 留过的一天：原图可以放大，短记还在
- 特别记忆：原话在小框里，不随压缩变短；标的人能删
- 隐藏：只影响自己，对方照常
- 空月份：`这个月还没有`
