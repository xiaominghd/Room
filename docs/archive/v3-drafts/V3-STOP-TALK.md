# V3 · 停与想聊：关门、开门、递一张卡片

> 属于 PRD，不动前端。
> 定稿方向：**停 = 关门（真的不接收）；想聊 = 开门（必须递一张卡片）；AI 只在开门时问一句；没有复述。**

---

## 0. 一句话

**门关上，话就进不来；门打开，要留一句话。**
停和想聊不是两个功能，是同一扇门的两个方向。

---

## 1. 停：关门

### 1.1 手势

- 输入框上沿一条暖光（把手）
- 按住往上拉：房间随手指变暗，0 → 86%
- 拉过 120px 松手 → **门停在半关**（暗 50%），不直接关
- 半关时，底部出现一行：今晚到这儿（可改、可空）+ 关 / 算了
- 5 秒不动 → 自动弹回，不算关门
- 点 关 → 门才真正关上

### 1.2 关门之后

| | 关门的人（A） | 对方（B） |
|---|---|---|
| 房间 | 暗，只剩输入框一圈光 | 正常 |
| 收到的消息 | **不显示，排队** | 正常 |
| 发消息 | 不能发（要发就先开门） | 能发，显示已发出 |
| 顶部 | 无 | `对方关着门` + 关门时那句 |
| 输入框 | 只剩一行：关门那句，可改可空 | 正常 |

- 关门时留一句（默认 `今晚到这儿`，可改，**不能空**）
- A 这边**看不到 B 发来的任何消息**，它们排队等着
- B 那边照常发，不知道 A 什么时候开

### 1.3 为什么真的不接收

停如果只是“暗”，那人还是会忍不住看；看了就会回，回了就没停成。
**关门就是关门**：这段时间的话进不来，开门时一起出现。

---

## 2. 想聊：开门

### 2.1 手势

- 门关着时，顶部一条细光（把手）
- 按住往下拉：房间随手指变亮
- 松手 → 门开

### 2.2 开门之后

```
1. 排队的消息先出现（按原来的时间排）
2. 输入框上方浮出一句 AI 的问题，不挡消息
3. 你在问题下面写一张卡片（1–2 句）
4. 递出去
```

- **消息先出现**，问题在旁边，不盖住任何东西
- 卡片写 1–2 句，最多 80 字
- 写完递出，门就算开完了

### 2.3 卡片去哪

| 对方状态 | 卡片 |
|---|---|
| 开着 | 直接递到对方手里 |
| 关着 | **放在门口**，等对方开门 |

- 对方关着时，他那边顶部会出现：`门口有一张卡片`
- 他开门时看到这张卡片——**这张卡片就是他的钥匙**，他可以直接开，不用先写
- 他读完可以回一张，也可以正常说话

### 2.4 锁

**开门需要一张卡片。**
这张卡片可以是你自己写的，也可以是对方留在门口的那张。

- 没有卡片，门不开
- 门口有卡片，门可以开（对方的卡片就是钥匙）
- 所以门不会空着开：要么你留一句，要么对方已经留了一句

## 3. 状态表

| 状态 | 关门的人 | 对方 | 入口 |
|---|---|---|---|
| 开 | 正常 | 正常 | — |
| 关门中 | 房间随手指变暗 | — | 上拉输入框上沿 |
| 关门 | 暗、无消息、只剩关门那句 | 正常 + `对方关着门` | — |
| 开门中 | 房间随手指变亮 | — | 下拉顶部 |
| 开门 | 排队消息出现 + AI 问题 | — | — |
| 写卡片 | 输入框上方一张纸 | — | — |
| 卡片递出 | 门开 | 开着：收到；关着：在门口 | — |
| 卡片在门口 | — | 开门时看到 | — |

---

## 4. AI 做什么、不做什么

### 4.1 做：开门时问一句

- 时机：门开、排队消息出现之后
- 只读三样东西：**关门那句、关门前最后几条消息、现在的时间**
- 出一句**邀请**，不是审问：

```
现在最想说什么？
昨天最让你担心的是哪一句？
想从哪一句开始说？
```

- 只问一次，不追问
- 问题显示在输入框上方，不挡消息

### 4.2 不做

- 不做复述（两边都写了卡片也不复述）
- 不评价、不总结、不判断谁对谁错
- 不读排队里的新消息，也不读更早的对话
- 失败就跳过：不出问题，直接让你写卡片

---

## 5. 卡片是什么

| 项 | 规则 |
|---|---|
| 长度 | 1–2 句，最多 80 字 |
| 样式 | 一张纸，不是气泡；和普通消息区分开 |
| 内容 | 你写的话，AI 不代写、不改写 |
| 送达 | 对方开着：递过去；关着：放在门口 |
| 门口等待 | 不参与压缩，直到被取走（否则还没看就变短了） |
| 被取走后 | 和当天消息一样，随 28 天压缩 |
| 一天多张 | 每次开门一张；多开多张 |

## 6. 文案

| 位置 | 文案 |
|---|---|
| 关门输入框 | `今晚到这儿` |
| 关门后的输入提示 | `说一句，门就开`（这句要不要留，见待拍板） |
| 对方顶部 | `对方关着门` |
| 门口有卡片 | `门口有一张卡片` |
| 卡片已递出 | `递过去了` |
| 卡片在门口 | `放在门口了` |
| AI 问题 | 见 §4.1 |

## 8. 验收

- 关门：拉到底只到半关，点「关」才真的关；5 秒不动自动弹回
- 关门：A 看不到 B 的消息；B 看到“对方关着门 + 消息会在他开门时出现”
- 开门：AI 问一句；写卡片；对方开着就收到，关着就放门口
- 锁：没有卡片开不了门；门口有卡片可以直接开
- 卡片：门口等待期不变短；取走后随当天压缩
- 不复述：两边都写了，也没有 AI 总结
