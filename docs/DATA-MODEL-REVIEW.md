## 0. 你已拍板的两条（覆盖 v0.1）

### 0.1 「留一天」锁什么

| 项 | 结论 |
|---|---|
| 锁什么 | **锁原文**（原文永远保留、原图永久） |
| 卡怎么办 | **停在最小压缩**，也就是 T+1 生成的那一版（v1，最详细） |
| 之后还压吗 | 不压。留过的那天，卡永远是最详细的那版 |
| 窗口 | **第 1 天到第 21 天**；第 21 天之后这一天就留不到了 |
| 没留的那天 | 第 21 天原文删除，卡压到 v4 |

**v0.1 写错的**：写着「留 = 卡冻结在当前 rev」。按你的规则，应该是「冻结在 v1」——第 20 天才留，看到的仍然是最详细那版，不是压缩了三轮的那版。

### 0.2 门口的卡和 21 天无关

我原来把卡片当成「那天的原文」，所以让它在第 21 天跟着消失。**这是错的**：

- 卡片是「递送」，不是那一天的话；门口的卡没被取走，就一直挂着
- 第 21 天删的是**那天的原文**（文字/图片/语音），不删卡
- 卡被取走时进消息流；剩下的照旧

**v0.1 要改的**：`messages` 的卡片行不参与按天清理；`days.purged_at` 只代表「非卡片的原文删干净了」。
