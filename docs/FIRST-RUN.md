# 第一次使用：从下载到「我们两个都在」

> 前 5 分钟。一个人从零开始，到房间里出现第二个人。
> 你只需要在「这一步会卡住人」的地方标一句。

---

## 第一步：下载之后

打开 App，看到一张启动图：一扇门，下面一行字。

**1.2 秒后**直接进登录页。没有引导页、没有滑动教程、没有「欢迎使用」。

---

## 第二步：登录页

```
[ 手机号 ]
[ 密码   ]

[ 登录 ]

没有账号，注册     忘记密码
```

**这一步我默认认识你**：手机号 + 密码，没有验证码。

如果我没注册过，点「没有账号，注册」。

---

## 第三步：注册

```
[ 手机号 ]
[ 密码   ]      ← 至少 8 位
[ 再输一次 ]

[ 注册 ]

☐ 我已阅读并同意《用户协议》和《隐私政策》
```

**不填用户名。** 注册完系统先给一个名字（比如「青禾」），进房后在「我的 → 个人资料」里改。

**关键的一步在这里**：注册完会发生什么，取决于我是怎么来的。

| 我怎么来的 | 注册完之后 |
|---|---|
| 自己下载、自己注册（没有邀请） | **自动建一间房**，直接进房 |
| 从别人的邀请链接来 | **不建房**，先进「输码」那一屏 |

没有「要不要创建房间」这种选择——来的方式决定了结果。

---

## 第四步：我的空房间

我建好房，第一次进房间，看到：

```
邀请一个人进来
```

没有输入框（一个人说话没意义），没有「发送」。
整个房间就一句话：`邀请一个人进来`，点了去房间信息。

---

## 第五步：房间信息

点那句「邀请一个人进来」，进到「房间信息」：

```
房间名
[ 我们的房间        ]   ← 可以改

[ 保存名字 ]

房间码
    7 K 2 M 9 X          ← 大字

[ 换一个码 ]  [ 分享 ]
```

我改了个名字叫「周末的岛」，点「分享」。

---

## 第六步：分享出去

系统分享面板打开，内容是一句话 + 一个链接：

> 阿澄 给你留了一个房间
> https://…/j/7K2M9X

我发给她。

---

## 第七步：她点开链接（还没装 App）

她看到的是一个网页：

```
有人给你留了一个房间

[ 去下载 ]
[ 已装，打开 ]
```

**网页里不注册、不填表、不输码。** 只是告诉她「有这么个地方」，然后去装 App。

链接里带着 7K2M9X，装好之后不用再问我要码。

---

## 第八步：她注册

她装好、打开，从链接进来，所以走的是「邀请来的人」那条路：

- 注册（手机号、用户名、密码、同意协议）
- **不建房**
- 直接到「输码」那一屏：

```
周末的岛
阿澄 给你留的房间

[ _ ][ _ ][ _ ][ _ ][ _ ][ _ ]

[ 进入 ]
```

她输 `7K2M9X`（或者链接已经带上了，直接点「进入」）。

---

## 第九步：她进来了

我这边：房间顶部还是「周末的岛」，但消息流里出现一行小字——**她进来了**。

她那边：房间里也是空的，两个人都在。

我们开始说话。

---

## 第十步：90 秒后

系统弹一次通知权限：

```
有人说话时，通知你。别的不会推。
[ 允许 ]  [ 先不用 ]
```

点「先不用」也不会再问。

---

## 会卡住人的六处（我列出来，你判断）


2. **空房只有一句「邀请一个人进来」**：够不够清楚？
3. **邀请 H5 只给下载**：她在网页上想先看看房间是什么样，看不到——这样对吗？
4. **输错码 5 次锁 1 小时**：如果她一时输错，会被锁住。要不要放宽到 10 次、或锁 10 分钟？
5. **第三个人拿到链接**：他打开会看到「这个房间已经满了」。要不要顺手给他一个「自己建一间」？
6. **我已经有房，点了别人的邀请链接**：会提示「你已经在另一间房里」，只能回自己的房间。要不要给「换房间」的路？（本版可能不做）

---

## 这一段里已经定好的（不用再讨论）

- 注册没有邀请 → 自动建房；从邀请来 → 不建房
- 房间码就是房号，一个码
- 网页端不注册、不输码，只引导下载
- 通知只在发第一条之前问一次
