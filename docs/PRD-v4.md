> 状态：2026-11-20 修订为 v4.7（改了什么见文末修订记录），替代 v3

## 0. 一页读懂

**一个只属于两个人的房间，和一本按天留着的相册。**

房间会收，相册会留。

房间只有两个人。打开就是说话：没有会话列表、没有已读、没有在线。
说过的话在房间里留 21 天。第 1 天，那一天收成一张图文卡，进相册；之后第 7、14 天，卡自己压一次；第 21 天，压最后一次，原文从房间消失，卡留下。

想停的时候，把门关上——收不到话，也不用解释。
想回来的时候，把门打开，写一张卡片。这扇门没有猫眼。

## 1. 术语

一个东西只用一个词。

| 词 | 指什么 |
|---|---|
| **房间** | 两个人说话的地方；也是相册与我的的入口 |
| **房间名** | 这间房叫什么；默认「我们的房间」，1–12 字，两个人都能改 |
| **房间码** | 进这间房的一串码（6 位，字母 + 数字，系统生成）；链接里也用它——**房号和开房码是同一个东西** |
| **原文** | 文字、图片、语音，说话时的样子；在房间里留 21 天 |
| **门** | 每个人各自一道：开着，或关着；两个人可以同时各关各的 |
| **停** | 把门关上；收不到话，也不能发 |
| **想聊** | 把门打开；只在停过之后发生 |
| **卡片** | 开门时写的那 1–2 句，递给对方；不是聊天消息 |
| **图文卡** | 系统整理的那一天：照片 + 一段话；**一人一篇**，只看得到自己那篇；不可改 |
| **此刻** | 你在那天的卡下写的一句话；一人一条；可选 |
| **短记** | 图文卡 + 此刻，合起来叫短记 |
| **留一天** | 把一天冻结：原文 + 原图 + 卡永久保留 |
| **特别记忆** | 在聊天里标一句原话或一张照片，让它 21 天后还在 |
| **日期行** | 房间里替代原文的那一行：`10 月 17 日 · 已收进相册` |

## 2. 房间

### 2.1 能发什么

| 类型 | 规则 |
|---|---|
| 文字 | 最多 2000 字；多行；系统 emoji；纯文本，不解析链接 |
| 图片 | 一条一张；拍照或相册；长边压到 1600 |
| 语音 | 单条 60 秒；按住录、上滑取消 |

不做：表情包、文件、位置、名片、转发、多选、复制、搜索。

### 2.2 发送

一条消息有四个状态：

| 状态 | 看到什么 |
|---|---|
| 发送中 | 气泡立刻出现，右下小点，不显示时间 |
| 已发送 | 小点消失，时间出现（服务端时间） |
| 失败 | `发送失败 · 重发` |
| 重发中 | 回到发送中，同一条，不复制 |

- 按发送立刻清空输入框；失败不弹窗、不震动
- 图片失败：图还留在气泡里（灰一点、中间一个 `!`），下面一行 `发送失败 · 重发`；重发用的是同一张图，不让人重选
- 自动重试 2 次（2 秒、8 秒）；之后手动重发
- 同一条用同一个 `client_id`，服务端幂等
- 草稿存本机，重启还在

### 2.3 接收

- 服务端给每条消息一个 seq，每房间单调递增
- WebSocket 推送；seq 接上就追加，有空洞先补拉，重复按 id 丢掉
- 排序只认 seq，不认手机时间
- 断线重连：先补拉，再接 WS
- 后台收推送；从通知进入滚到那条消息

### 2.4 时间

- 显示时间一律用服务端时间
- 离线消息显示服务端接受时间（20:00 没网、20:30 发出，显示 20:30）
- 日期分隔：今天 / 昨天 / `10 月 17 日`；跨年显示年份

### 2.5 引用与撤回

**引用**
- 长按 → `引用并回复`；引用整段，长文可展开，不截字
- 引用块不显示原消息时间；不套娃
- 引用只记 id，不复制文字，按原消息的当前状态显示：
  - 原文还在：显示全文
  - 原文已进卡：`10 月 9 日 · 已收进相册`
  - 原文撤回：`原消息已撤回`

**撤回**
- 只有自己 2 分钟内的消息能撤；点了就撤，不二次确认
- 撤回后完全消失，对方侧淡出，不留痕
- 被引用过的消息撤回后，引用块显示 `原消息已撤回`

### 2.6 消息在房间里的寿命

- 房间保留最近 21 天的原文
- **按天切，不按条**：一天的原文在过了 21 天之后的 0 点一起消失；房间里一天只会留一行日期，不会一条一条地少
- 第 21 天，那一天收成一行 `10 月 17 日 · 已收进相册`，点开是相册的卡
- **留过的一天**：在留的当下就从房间收走，只留一行 `10 月 17 日 · 留过`
- 没留的一天：第 21 天原文删除，照片转缩略图
- 没照片的日子也有卡（纯文字），月历格子里是一个点

## 3. 门

### 3.1 停：关门

**手势**
- 输入框上沿一条光，是把手
- 按住往上拉，房间随手指变暗
- 拉过阈值松手 → 门停在半关（暗 50%），不直接关
- 半关时底部：一个空输入框（占位 `关门之前，说点什么吧`）+ `关` / `算了`；不能空
- 松手后就停在这儿，**不自动弹回**：这句话要现写，不能被打断；只有点 `算了` 才回房间，点 `关` 才真正关上

**关门之后**

| | 关门的人 | 对方 |
|---|---|---|
| 房间 | 暗，只剩输入框一圈光 | 正常 |
| 收到的消息 | 不显示，排队 | 正常 |
| 发消息 | 不能发 | 能发，显示已发出 |
| 顶部 | 无 | `对方关着门` + 关门那句 + `你的消息会在对方开门时出现` |

- 关门那句不能空；它是这段安静的作者
- 关门期间，关门的人不接收任何推送

### 3.2 想聊：开门

**想聊只在停过之后存在。**

- 门关着时，顶部一条细光，是把手；按住下拉，房间随手指变亮
- 松手 → 门开：
  1. 房间亮起，输入框上方浮出 AI 的一句问题，标「AI」
  2. 写一张卡片（1–2 句，最多 80 字）
  3. 递出去
  4. 递完，排队的消息才按原时间出现

**卡片去哪**

| 对方状态 | 卡片 |
|---|---|
| 开着 | 直接递到手里 |
| 关着 | 放在门口，等他开门 |

- 门口有卡片时，他开门看到，这张卡片就是他的钥匙，他可以直接开
- **开门需要一张卡片**：自己写的，或者门口对方留的那张
- 门口等待的卡片不参与压缩；被取走后随当天压缩

### 3.3 AI 只问一句

只在开门时问，只读三样：关门那句、关门前最后几条消息、现在的时间。

出的是邀请，不是审问：

```
现在最想说什么？
昨天最让你担心的是哪一句？
想从哪一句开始说？
```

- 只问一次，不追问
- 不做复述、不评价、不总结、不判断谁对谁错
- 失败就跳过，直接让人写卡片

### 3.4 没有猫眼

- 关门期间看不到任何消息；想看，只能开门
- 卡片没递出去之前，排队的消息一条都不出现：门亮着，但看不到话
- 开门是准备说话，不是来看一眼
- 停不是惩罚，是边界；关门那句就是它的作者

## 4. 记忆

### 4.1 时间线

| 时间 | 房间 | 相册 |
|---|---|---|
| 0–21 天 | 原文都在 | **第 1 天**生成一张卡 |
| 第 7 / 14 天 | 不动 | 卡自己压一次 |
| 第 21 天 | 原文消失，只留一行日期 | 压最后一次 + 定型，永久保留 |

- **每天都有卡**：有内容的日子都生成卡，只是内容不同——有照片就带照片，纯文字就只有一段话，只有吵架的日子只有一行事实
- 留过的一天：原文永久保留，卡冻结
- 没留的：第 21 天原文删除，照片转缩略图
- 特别记忆的原话单独保存，21 天后还在
- 被标的这条，在聊天里带一个小点（谁标的都显示）；原文页里也带同样的点
- **每个人只看得到自己标的**：小点、卡末尾的小框，都只显示自己标的；对方标了什么、标了几条，你看不到
- 两个人都可以标同一条，各有一份，互不影响
- **两个入口**：聊天里长按那条原文 → 特别记忆 / 取消特别记忆；那天的卡里，小框后面 → 删
- **删只删自己的**：你删了，对方那份还在（如果他也标了）；对方删了，你这份不受影响
- **21 天内删**：下一次压缩（第 7/14/21 天）会看到你少标了一条，重新分配重要程度、重新写卡；**已经生成的那版卡文字不改**
- **21 天后删**：原文已经没了，删掉就等于把你那句快照删了——卡上那行消失，没有 AI 参与
- **进卡时两个人标的都算**：卡是共同的，压缩会把双方标过的原话都当重点，但卡上不写是谁标的
- 压缩失败不是"没有卡"：算法出错时，卡上就写那天的事实；卡不会因此消失（写不出来时只有日期，也算一张卡）

### 4.2 图文卡

- **日记一人一份**：同一天，两个人各有一篇 AI 整理；A 那一篇只看 A 标的原话，B 那一篇只看 B 标的——**互相看不到对方那篇**
- 照片按当天顺序排，最多 9 张；没有照片就不放；照片是两人共用的
- 卡上标「AI 整理」；生成后不可改
- 只写那天的事实；不写争执：不写指责、反问、翻旧账；一天只有吵架，卡上不写争执，只留一行事实（卡还在）
- **被标过的原话，卡里必须出现**（原样或明显改写，不能压没）：特别记忆是给压缩算法的输入，不只是结果
- **怎么写、怎么压，本版不细化**：文字交给单独的算法（写作 + 压缩），PRD 只定看得到的样子（见 §13）

### 4.3 此刻

- 一人一条；只有本人能改、能删
- 唯一入口是相册：打开那一天的卡，在卡下写；房间里没有入口、不提示、不推送
- 不参与压缩；AI 不读、不改、不接话
- 21 天后仍然能写：AI 卡定型，此刻是活的
- 不写就没有，不出现「还没有此刻」
- 可以不相关：`我爱你`、`今天很累`、`想抱抱你`，不需要解释那天发生了什么

### 4.4 两种留

| | 在哪留 | 留什么 | 后果 |
|---|---|---|---|
| **留一天**（主） | 相册里点「留这一天」 | 原文 + 原图 + 图文卡 | 冻结整天；原文搬进卡里，从「看那天的原文」进 |
| **特别记忆** | 聊天长按一条 | 这句保原话；这张保缩略图 | 21 天后仍在 |

- 留一天只能留已经生成卡的日子（第 1 天起）；当天的日子不能留
- 留一天后，这一天从房间收走，只留一行 `10 月 17 日 · 留过`；原文在卡里，不在房间
- **留是两个人的票，谁留都算留**：A 留 B 留 → 留；A 留 B 没留 → 留；A 取消、B 还留着 → 留；两个人都取消 → 回到没留
- **两个人看到的一样**：留过的那天，双方都看到 `留过`、都能从卡里看那天的原文
- **21 天内可以取消自己那一票**：我取消了、对方还留着，这一天仍然是留过；两个人都取消，原文回到正常的时间（第 21 天删）、卡继续往下压
- **21 天后锁定**：不再有取消入口
- **删的时间只看消息是哪一天的**：10 月 16 日的原文，第 21 天是 11 月 6 日；第 16 天取消留，仍然 11 月 6 日删，不重新计时
- 留过的那天，卡停在**最小压缩**那一版（第 1 天生成的，最详细）——留住的是当时的样子
- 特别记忆：谁标谁删（聊天里长按 / 卡上小框两个入口）；**删了两个人都看不见**；21 天内删会被下一次压缩看到，21 天后删只删掉那句快照
- 21 天后：留一天的原文仍可看；没留的原话和原图都没了

### 4.5 照片与原文

- 留过的一天：原文永久保留；照片保留原图
- 没留、有照片：第 21 天原文删除；照片缩略图（长边 640），不能放大；卡还在
- 没照片：卡还在（纯文字）；月历格子里是一个点

## 5. 相册

### 5.1 月历

| 那天的状态 | 格子里 |
|---|---|
| 留过 | 清晰原图缩略 + 日期 |
| 没留、有照片 | 略柔的缩略图 + 日期 |
| 没留、没照片 | 小圆点 + 日期（点开是纯文字卡） |
| 什么都没有 | 空 |

- 只显示有内容的月份；一直往回翻
- 不做「那年今日」、不做搜索、不做统计

### 5.2 一天的卡

```
10 月 17 日

〔一段话：那天发生了什么〕   ← 图文卡，标「AI 整理」（写法本版不细化，见 §13）

[照片] [照片] [照片]

此刻
  栗子：我爱你
  阿澄：今天很累

┌──────────────────────┐
│ 「你先吃，我不饿」      │                     ← 特别记忆
└──────────────────────┘

留过 / 留这一天
看那天的原文（留过才有）
```

- 此刻放照片下面、特别记忆小框上面
- 小框永远最后
- 照片网格三列，最多 9 张，多的收起来
- 留过的照片可放大；没留的不能放大

### 5.3 删除

- 删小框：标它的人可删，只在自己这边少一条
- 此刻：本人可改可删；对方不能动
- 不删天、不删照片

## 6. 账号与准入

### 6.1 身份

| 东西 | 作用 | 规则 |
|---|---|---|
| 手机号 | 唯一编号 | 全系统唯一；登录用；以后接实名 |
| 用户名 | 别名 | 房间内唯一；可改；不能登录 |
| 密码 | 唯一凭证 | ≥ 8 位；允许纯数字 |

没有恢复码、没有短信验证码、没有实名。

### 6.2 注册、登录、找回

- 注册：手机号 + 密码（两次）；**不填用户名**；**没有邀请** → 注册完自动建房、直接进房；**从邀请链接来** → 不建房，先输房间码（§6.3）
- 系统给一个默认名字（两字，从一组中性词里挑，比如「小满」「青禾」）；进房后可以改，**改名不通知对方**
- 用户名只在房间里显示，不能拿来登录
- 登录：手机号 + 密码；refresh token 30 天；单设备，新登录踢旧
- 找回：人工
  1. 用注册手机号发短信到运营者号码，内容写「找回密码」
  2. 核对发送号码与注册号码一致
  3. 回一条 8 位临时密码（24 小时、一次、登录后强制改密）
  4. 非注册号发来，不处理
- 换手机号：密码 + 新号（二次确认）；旧号释放
- 退出登录：清本机；再登录回到同一间房

### 6.3 进房

- 第一个账号注册后自动建房，同时得到**一串房间码**（6 位，字母 + 数字，去掉了 0/O/1/I/L 这类看着像的字符），房间默认叫「我们的房间」
- **房间码就是房号，一个码管两件事**：贴在邀请链接里（`/j/7K2M9X`），也可以直接手输
- 邀请链接带房间码；第二个人注册后输入这串码
- **输对码就直接进房，不需要房主确认**
- 房间上限 2 人；满员后码立即失效（链接和手输都不再能进）
- 房间码可改：改了旧码立刻作废；只在活着的时候能改（满员后不给改，也进不来）
- 房间码就是门禁：谁拿到码谁就能进；分享前想清楚

### 6.4 一账号一房

- 同一账号同时只能在一间房
- 允许一个人注册多个号、进多间房（靠实名收口）
- 离开房间：入口在「我的」（那一行写「离开」）；本版只留入口，不定行为。离开之后这间房是什么样（留房期、只读相册、能不能回来）本版不做，见 §13

### 6.5 账号管理

- 改用户名、改密码、换手机号、退出、注销
- 注销：7 天冷却，期间登录可撤销；执行后身份删除，共同相册只读留给对方

## 7. 通知

只推一件事：新消息。

不推：停 / 关门 / 想聊 / 门开了 / 卡片被取走 / 导出 / 结束。

- **合并**：同一房间只保留一条消息通知；第一条响，后续更新同一条、不响，正文后加数字 `有新消息 3`
- 数字 = 自上次进房间以来的新消息数；进房间清零；`99+`
- **卡片没有单独通知**：卡片是消息流里的一条（一张纸），跟着新消息合并走；对方关着门时它放在门口，本来就不推
- 锁屏默认不显示内容；可在设置里打开，打开时写明代价
- 不做 App 图标角标
- 关门期间，关门的人完全不推
- 点通知：消息还在 → 滚到那条；已进卡 → 那天的卡；已定型 → 相册那天的卡
- 权限：进房后、发第一条前，一句 `有人说话时，通知你。别的不会推。`
- 今晚不提醒：到第二天 8:00，不是停

```
├─ 资料卡：栗子 · 和 阿澄 在「周末的岛」        →
├─ 卡一（账号）：账号与安全 / 通知
├─ 卡二（房间）：房间信息 / 导出 / 这个房间怎么运转 / 离开房间
└─ 底栏：隐私政策 · 用户协议 · v1.0.0 · 反馈
```

- **房间信息**（新）：房间名 + 房间码，两个都在这一页改
  - 房间名：默认「我们的房间」，1–12 字，**两个人都能改**；改名不通知、不留记录
  - 房间码：6 位，字母 + 数字，系统生成；**可改**（旧码立刻作废）；满员后不再能改
  - 同一页放：复制链接、系统分享、一行「谁拿到这串码，谁就能进」
- 离开房间放这一层，不放个人资料；本版只有入口和说明，离开之后见 §13
- 一级不放开关；开关进二级
- 账号与安全：手机号（打码、换绑）/ 修改密码 / 退出登录 / 注销（最底、红字）
- 通知：新消息通知 / 锁屏显示内容 / 今晚不提醒
- 导出：范围（全部 / 近 30 天 / 近 7 天）、格式（PDF / 纯文本）、生成；对方收到一条提示；链接 7 天
- 运转说明：记忆、AI、停、想聊；「怎么关掉」等结束定了再补
- 不做头像、多账号切换、免打扰时段、客服系统

### 8.1 房间名和房间码出现在哪

| 地方 | 显示什么 |
|---|---|
| 房间顶部 | 房间名（就是标题，不再是写死的「我们的房间」） |
| 我的 · 资料卡 | 房间名 |
| 邀请页 / 邀请 H5 | 房间名 + 「谁给你留的」 |
| 房间信息 | 房间名 + 房间码 + 复制/分享 |
| 个人资料、导出 | 房间名（不再显示「房间 ID」，因为它和房间码是同一个东西） |

## 9. 隐私与安全

| 项 | 规则 |
|---|---|
| 原文 | 留 21 天；第 21 天删除（留过的除外） |
| 图文卡 | 定型后永久；没留的照片是缩略图 |
| 此刻 | 随当天卡保存；只本人可改删；AI 不读 |
| 账号 | 手机号 + 密码直到注销；不存证件、不存真名 |
| AI | 第 1 天读原文生成卡；第 7/14/21 天读**上一版卡**再压；开门时读关门上下文；不留存、不训练 |
| 找回 | 人工；只认注册手机号发来的短信 |
| 日志 | 不记消息内容、不记手机号、不记密码 |
| 备份 | 不含消息正文 |
| 传输 | 全站 TLS；密码与令牌哈希；限流 |

## 10. 不做

- 已读、送达、在线、正在输入
- 复制、转发、多选、消息搜索
- 说给自己、本机笔记
- 头像、个人主页、多账号切换
- 纪念日、打卡、年度回顾、统计
- 推送钩子（「你很久没来了」）
- 表情商店、红包、文件、位置
- 公开注册、多租户、订阅、iOS

## 11. 指标

| 指标 | 目标 |
|---|---|
| 北极星：双人周留存 | 两个人都在 7 天内各打开 ≥ 3 天 |
| 邀请完成率 | ≥ 55% |
| 进房 → 第一条消息 | ≥ 70%，中位数 ≤ 60 秒 |
| 留的转化 | ≥ 20% 活跃房间每周至少留 1 天 |
| 通知关闭率 | < 30% |
| 21 天定型 / 相册丢失 | 0 |
| 导出成功率 | ≥ 99% |

## 12. 验收

- [ ] 注册：没有邀请就建房（带一串房间码）；从邀请链接来的不建房，输码直接进房；满员后码失效
- [ ] 关门后收不到消息；开门后要先递一张卡片，消息才按原时间出现；没有卡片开不了门
- [ ] 引用整段；原文进卡后引用显示「已收进相册」；撤回后引用显示「已撤回」
- [ ] 第 1 天有图文卡；第 21 天原文整日消失，只剩日期行（不会一条一条地少）
- [ ] 留一天：原文搬进卡，从「看那天的原文」进；房间只留 `留过`
- [ ] 特别记忆的原话 21 天后还在
- [ ] 此刻：一人一条、只有本人能改删、21 天后还能写、房间无入口
- [ ] 通知合并成一条带数字；锁屏默认无内容；无图标角标
- [ ] 忘密码：注册号发短信 → 临时密码 → 强制改密
